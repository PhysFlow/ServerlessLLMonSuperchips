# Contributing

## Branches

Create a branch for each change. Do not commit directly to `main`.

Use one of these prefixes:

- `feat/`
- `fix/`
- `refactor/`
- `test/`
- `docs/`
- `ci/`

## Testing

Run the relevant tests before opening a pull request. Tests that require a GPU may be validated manually.

## Pull Requests

Open a pull request for every change and complete the pull request template.
Record any required GPU validation and its result in the pull request.
